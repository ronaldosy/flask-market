## Environment variables

+ MARKET_DB_USER
    + This variable will store db user information

+ MARKET_DB_PWD
    + This variable will store db password

+ MARKET_DB_HOST
    + This variable will store db host 

+ REDIS_HOST
    + This variable will store redis host information, redis used to store session information
